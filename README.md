# 🌬️ Трекер вітру — Донецька та Харківська області

Веб-додаток для відстеження **напрямку та швидкості вітру** в обраному регіоні.
Поточні умови + погодинний і денний прогноз. Чисті **HTML + CSS + JavaScript**,
без збірок і залежностей.

## ✨ Можливості

- **Поточний вітер**: швидкість (м/с), напрямок, пориви, сила за шкалою Бофорта
- **Компас** із стрілкою, що показує, куди дме вітер
- **Погодинний прогноз** на 24 години (швидкість + напрямок + пориви)
- **Прогноз по днях** (до 5 днів): макс. вітер, пориви, переважний напрямок
- Вибір локації (міста Харківської та Донецької областей)
- Автооновлення кожні 10 хвилин, збереження останньої локації
- Адаптивний дизайн (телефон / десктоп)

## 📡 Джерело даних

[Open-Meteo](https://open-meteo.com) — безкоштовний API погоди, **без ключа й реєстрації**.
Запит виконується напряму з браузера. Швидкість запитується в м/с.

> Напрямок вітру вказується **метеорологічно** — звідки дме вітер
> (наприклад, «Пн» = північний вітер, дме з півночі на південь).

## 📁 Структура

```
.
├── index.html       # Розмітка
├── css/style.css    # Стилі, компас, адаптив
├── js/app.js        # Локації, запити до API, рендер
└── README.md
```

## 🚀 Запуск

Відкрийте `index.html` у браузері. Або локальний сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 🌐 Публікація (GitHub Pages)

Settings → Pages → гілка з кодом, папка `/root`.
Сайт відкриється за `https://<user>.github.io/<repo>/`.

## 🛠️ Додати власну локацію

У файлі `js/app.js` у масиві `LOCATIONS` додайте обʼєкт з назвою та координатами:

```js
{ name: "Нове місто", lat: 48.1234, lon: 37.5678 }
```
