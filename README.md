# S21 Ultra — лендінг флагманського смартфона

Сучасний односторінковий сайт (landing page) на чистих **HTML + CSS + JavaScript**.
Без збірок і залежностей — відкривається в будь-якому браузері.

## ✨ Можливості

- Адаптивний дизайн (телефон / планшет / десктоп)
- Темна тема з градієнтами та анімаціями
- Анімовані лічильники характеристик
- Поява блоків при прокрутці (IntersectionObserver)
- Інтерактивний вибір кольору
- Мобільне меню (бургер)
- Форма замовлення з валідацією
- Живий годинник на макеті телефона

## 📁 Структура

```
S21ULTRA/
├── index.html        # Розмітка сторінки
├── css/style.css     # Стилі та адаптив
├── js/main.js        # Інтерактивність
├── assets/           # Зображення (за потреби)
└── README.md
```

## 🚀 Запуск локально

Просто відкрийте `index.html` у браузері. Або запустіть локальний сервер:

```bash
# Python 3
python3 -m http.server 8000
# далі: http://localhost:8000
```

## 🌐 Публікація (GitHub Pages)

1. Settings → Pages
2. Source: гілка з кодом, папка `/root`
3. Сайт буде доступний за адресою `https://<user>.github.io/S21ULTRA/`
