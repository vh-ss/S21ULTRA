# 🌬️ WindMe — інтерактивна мапа вітру

Веб-додаток для відстеження **напрямку та швидкості вітру** на інтерактивній мапі.
Обери до **3 областей** у налаштуваннях, натисни на місто — і побачиш деталі вітру
та прогноз. Чисті **HTML + CSS + JavaScript** + [Leaflet](https://leafletjs.com)
для мапи.

## ✨ Як це працює

1. **Налаштування (⚙)** — обери до **3 областей** (зберігається у браузері)
2. **Мапа** показує міста обраних областей маркерами з кольором (сила) і стрілкою (напрямок)
3. **Клік по місту** → відкривається вікно з деталізацією:
   - компас зі стрілкою напрямку
   - поточна швидкість (м/с), напрямок, пориви, сила за шкалою Бофорта
   - погодинний прогноз на 24 години
   - прогноз по днях (до 5 днів)
4. **Міста (📍)** — додавай власні міста за назвою (пошук через геокодер) або
   видаляй будь-які міста; зміни зберігаються у браузері. Видалені вбудовані
   міста можна повернути.

## 🌍 Доступні області (7, до 3 одночасно)

Харківська · Донецька · Луганська · Дніпропетровська · Запорізька · Полтавська · Сумська
(разом 72 міста)

## 📡 Джерело даних

- Погода: [Open-Meteo](https://open-meteo.com) — безкоштовний API, **без ключа**
- Мапа: [Leaflet](https://leafletjs.com) + темні тайли CARTO/OpenStreetMap

> Напрямок вітру — **метеорологічний** (звідки дме). Швидкість у **м/с**.

## 📁 Структура

```
.
├── index.html       # Розмітка: мапа + модальні вікна
├── css/style.css    # Стилі: мапа, маркери, модалки, компас
├── js/app.js        # Локації, мапа, налаштування, запити, рендер
└── README.md
```

## 🚀 Запуск

Відкрийте `index.html` у браузері (потрібен інтернет для мапи та даних). Або:

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 🌐 Публікація (GitHub Pages)

Settings → Pages → гілка з кодом, папка `/root`.

## 🛠️ Додати область або місто

У `js/app.js`, масив `LOCATIONS` — додайте групу або точку
`{ name: "Місто", lat: 0.0, lon: 0.0 }`. Ліміт одночасних областей — `MAX_OBLASTS`.
